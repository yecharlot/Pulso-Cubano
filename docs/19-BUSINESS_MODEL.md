# BUSINESS_MODEL.md — Pulso Cubano

## Problema

La información económica y comercial sobre Cuba está fragmentada (clasificados, búsqueda, medios, boca a boca). Un empresario o inversor no tiene un **observatorio continuo** con evidencia y metodología.

## Solución

Pulso Cubano agrega observaciones legítimas, las normaliza, construye series históricas y publica inteligencia **explicable** (evidence, confidence, coverage, counter-signals).

## Qué no es

No es un clasificado, ni una red social, ni un scraper ilegal, ni un dashboard vacío.

## Cliente (quién paga)

| Segmento | Valor |
|----------|--------|
| MIPYMES / emprendedores | ¿Qué está pasando en mi categoría/municipio? |
| Proveedores / distribuidores | ¿Dónde crece la demanda *observable*? |
| Inversores / analistas | Señales sectoriales y geográficas con metodología |
| Investigadores | Series históricas y cobertura explícita |
| Enterprise / instituciones | API, reportes, cobertura ampliada |

## Producto

Market Intelligence en capas:

| Tier | Oferta |
|------|--------|
| FREE | Public Market Pulse (agregados, metodología) |
| PRO | Business intelligence / categoría |
| PREMIUM | Señales profundas, alertas |
| GROWTH | Campaign intelligence |
| DATA / API | Feeds y API agregada |
| RESEARCH | Reportes a medida |
| ENTERPRISE | Contratos institucionales |

## Monetización (diseño, no promesa de ingresos)

- Recurrente: suscripciones  
- Transaccional: reportes / campañas  
- Escalable: API / datasets agregados  
- Enterprise: contratos  

**No se venden datos personales.** El valor está en agregación, normalización, historia y analítica.

## Moat

Años de observaciones + taxonomía + grafo de mercado + provenance + calibración.  
El código se copia; el histórico calibrado no.

## Flywheel

Más datos → mejor inteligencia → más usuarios → más first-party → mejores modelos → más valor → más datos.

## Go-to-market (orden)

1. **GTMO Market Pulse** público periódico  
2. Audiencia + feedback  
3. Business Pulse  
4. Premium / alertas  
5. Campaigns  
6. API  

## Riesgos comerciales

Cobertura incompleta, sesgo de fuentes públicas, regulación de acceso a datos, confianza. Mitigación: metodología pública, capas observed vs official, no promesas de predicción garantizada.
