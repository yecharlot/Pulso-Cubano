# Visión — Pulso Cubano

**La capa de inteligencia del mercado cubano (observado).**

Transforma señales dispersas y públicas en:

DATA → EVIDENCE → SIGNAL → INSIGHT → OPPORTUNITY → ACTION → RESULT → LEARNING

Distingue siempre **REAL MARKET** vs **OBSERVED MARKET**.  
No inventa ventas, share, ni demanda real a partir de anuncios o búsquedas.
