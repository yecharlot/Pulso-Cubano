# Metodología (borrador)

- Toda métrica de mercado se etiqueta `observed_market` salvo datos oficiales explícitos.  
- Anuncios ≠ transacciones. Búsquedas ≠ compras.  
- Confidence y coverage son obligatorios en Observation.  
- Pulse Score v0: promedio ponderado documentado en `metrics/pulse.go`.  
- Cambios metodológicos versionados (`method_version`).
